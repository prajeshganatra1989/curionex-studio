# Editorial Principles — Curionex Content Standard

These principles are stored on the active Content Standard and injected into every AI draft/review prompt.

## Core principles

1. **One memorable idea** — a Short carries a single takeaway
2. **Clear explanation** — respect the viewer’s intelligence without fluff
3. **High retention** — curiosity → context → payoff without dead air
4. **No fluff** — every line earns its place in spoken narration
5. **Respect viewer intelligence** — no condescension, no manufactured mystery beyond the hook

## Structure

Hook → Context → Explanation → Twist → Payoff → CTA

## Hook rules

- Curiosity in the first breath
- Honest promise within five seconds
- No misleading clickbait

## Fact & citation

- Never invent statistics or quotes
- Label uncertainty and theory vs evidence
- Prefer authoritative sources
- Flag claims that still need human verification
