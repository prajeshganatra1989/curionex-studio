## How to use this Bible

| Role | Use |
|------|-----|
| **Human narrator** | Chapters 1–9 before every session; Appendix A before delivery |
| **ElevenLabs / AI operator** | Chapters 10–12 + persona card; never chase “dramatic” presets |
| **Editor / director** | Chapters 5, 8, 13–14 as the audition and mix gate |
| **QA** | Chapter 13 checklist on every voiceover |
| **Writers** | Write for the ear using Editorial Bible; this Bible governs *performance* |

**Precedence**

- **What to say** → Editorial Bible + Content Standard + Master Script  
- **How it should sound** → this Voice & Narration Bible  
- Studio word-count tooling defaults to **~150 WPM** / **60s**; performance pacing below may run slightly slower for clarity and still land in the **55–60s** Gold window when scripts are **150–170** spoken words.

## 1. Voice Philosophy

### What Curionex should sound like

Curionex sounds like a trusted guide sitting beside you—not a host performing at you.

| Quality | Meaning in performance |
|---------|------------------------|
| **Calm** | Steady breath; no panic climb |
| **Confident** | Clear claims without bluffing; soft certainty where evidence is firm |
| **Curious** | Genuine interest in the question—shared discovery |
| **Warm** | Human temperature; never cold lecture |
| **Intelligent** | Precise wording; respectful of complexity |
| **Trustworthy** | Honest hedges sound natural, not apologetic |

> Pull quote: *National Geographic calm. BBC Earth patience. Pixar emotional honesty—without cartoon energy.*

### What Curionex must never sound like

| Never | Why |
|-------|-----|
| Dramatic / movie trailer | Brand break; spectacle over trust |
| Robotic / flat TTS default | Feels like spam, not Curionex |
| Overly excited | Undermines scientific integrity |
| Clickbait suspense | Viewers feel sold |
| Academic drone | Loses wonder |
| Radio DJ / TikTok hype | Wrong cultural register |

### Sonic brand test

Mute the picture.  
If a regular viewer still says “that sounds like Curionex,” the performance passed.

## 2. Audience Emotion

### Target feeling

> **"I'm learning something amazing from someone I trust."**

| Desired | Forbidden substitute |
|---------|----------------------|
| Quiet wonder | Shock |
| Recognition (“I’ve felt that”) | Manipulation |
| Clarity after mystery | Confusion sold as deep |
| Warm close | Hard sell |
| Respect for unknowns | Fake absolute answers |

### Not this

- “I’m being sold something.”  
- “I’m being hyped into clicking.”  
- “I’m being talked down to.”  
- “I’m watching a trailer for a disaster movie.”

### Emotional contract with Editorial Bible

The script earns the emotion; narration **reveals** it.  
Never add emotion the Master Script did not earn.

## 3. Narration Style

### Natural speech

- Speak as if explaining to one intelligent friend.  
- Prefer conversational rhythm over “read-aloud essay.”  
- Allow natural breath—do not stitch sentences airtight.  
- Smile lightly on wonder lines; never grin through science.  
- Reflection moments (endings) settle the voice downward, not upward.

### Sentence pacing

| Line type | Performance |
|-----------|-------------|
| Short punch lines (“A year is still a year.”) | Clean; slight weight; no rush |
| Stacked short beats (“It lubricates. It protects.”) | Even spacing; equal dignity |
| Longer explanatory lines | Smooth; one idea; breathe at commas if needed |
| Questions | Genuine curiosity—not quiz-show |

### Moment types

| Moment | Sound |
|--------|-------|
| **Smile** | Tiny warmth on demystifying lines (“A magnet isn’t magical.”) |
| **Wonder** | Soft lift + micro pause after cosmic or intimate reveals |
| **Reflection** | Slower, quieter, more space—especially GS-008 / GS-010 style endings |
| **Integrity hedge** | Calm, matter-of-fact (“scientists still study that piece”)—never sheepish |

### Breathing

- Breathe at idea boundaries, not mid-technical phrase.  
- Never gasp for trailer energy.  
- If a take sounds breathless, redo at lower intensity—not higher speed.

## 4. Speaking Speed

### Studio baseline

| Setting | Typical value |
|---------|----------------|
| Target duration | **55–60 seconds** |
| Master Script length | **150–170** spoken words |
| Planning WPM (Studio default) | **~150 WPM** |

### Performance WPM ranges

Aim for **comfortable clarity**. Prefer the lower half of a range when the idea is dense.

| Beat | Target WPM | Feel |
|------|------------|------|
| **Overall average** | **145–155** | Natural guide |
| **Hook** | **130–145** | Invitation; let the image land |
| **Scientific explanation** | **145–155** | Clear; unhurried intelligence |
| **Twist** | **135–150** | Slight hold; discovery weight |
| **Perspective shift / ending** | **125–140** | Reflective; afterimage |
| **CTA** | **140–150** | Soft; never barked |

### Timing notes

- If a Gold script runs long at reflective pace, **trim words in editorial**—do not race the VO to fit.  
- If it runs short, do not pad with fake awe—hold pauses or accept a 55s cut.  
- Never compress the ending to save the CTA.

### Read-aloud calibration

Narrators: time three cold reads of the Master Script.  
Median should fall in **55–62s** including intentional pauses. Adjust pause length before adjusting “personality energy.”

## 5. Emotional Curve

Map intensity (1 = intimate calm · 5 = peak discovery). Curionex **never** opens at 5.

```text
Hook (2–3)
  ↓
Curiosity / setup (3)
  ↓
Explanation (2–3)
  ↓
Discovery / twist (3–4)
  ↓
Perspective shift (3–4, quieter)
  ↓
Warm close + CTA (2)
```

| Stage | Intensity | Direction |
|-------|-----------|-----------|
| Hook | 2–3 | Invite, don’t explode |
| Curiosity | 3 | Open the question |
| Explanation | 2–3 | Competence + clarity |
| Discovery / twist | 3–4 | Peak *insight*, not volume |
| Perspective shift | 3–4 but softer | Deeper, not louder |
| Warm close | 2 | Trust landing |
| CTA | 1–2 | Whispered invitation |

### Rules

1. **Never peak too early.** Trailer energy in the first two seconds is a fail.  
2. Peak is **understanding**, not loudness.  
3. Endings may be emotionally strong while acoustically soft (GS-010, GS-008).  
4. Explanation should feel stable—listeners need cognitive room.

## 6. Pronunciation Rules

### Scientific terms

| Rule | Guidance |
|------|----------|
| First mention | Clear, slightly slower; no apology |
| Familiar terms | Natural pace (gravity, magnet, dream) |
| Rare terms | Prefer script simplification; if kept, pronounce fully once |
| Domains / jargon | Only if the Master Script includes them (e.g. “domains”)—then teach by tone, not by footnote |

### Names

- Prefer established English science pronunciation (Chicxulub ≈ *CHEEK-shoo-loob*—confirm before session).  
- Never invent flamboyant pronunciations for flair.  
- If unsure, verify with editorial—**do not guess on camera**.

### Numbers, years, units

| Form | Speak as |
|------|----------|
| 66 million | “sixty-six million” (not “66M”) |
| Years ago | “sixty-six million years ago” — even, not dramatic |
| ~10 km | Prefer script wording (“mountain-sized” / “about ten kilometers”)—avoid stacked units if script simplified |
| Percentages | “twenty-five percent” (if present)—no sports-announce punch |
| Large counts | Group naturally: “thousands of times a day” |

### Acronyms & abbreviations

| Prefer | Avoid |
|--------|-------|
| Expand on first need if script allows | Alphabet soup VO |
| “Wi‑Fi” as *why-fye* | Spelling out W-I-F-I unless teaching letters |
| Skip K–Pg / similar in VO unless script requires | Geological acronym flex |

### Latin / taxonomic

Usually **avoid in Shorts VO**. If present (rare), slow and plain—no Classical theater.

### When to simplify

If pronunciation fights retention, **change the script** (Editorial), don’t “perform through” the tangle.

## 7. Pause System

Pauses are part of the brand. They create understanding and trust.

| Pause type | Length (guide) | Where |
|------------|----------------|-------|
| **Micro pause** | ~0.15–0.3s | Commas; list beats (“It lubricates. ‖ It protects.”) |
| **Idea pause** | ~0.4–0.7s | Between explanation blocks |
| **Reflection pause** | ~0.7–1.2s | Before/after perspective shift lines |
| **CTA pause** | ~0.4–0.6s | Breath before soft CTA |

### Examples (Founding Collection spirit)

> “Think back to this year. ‖ Where did it go?”

> “A magnet isn’t magical. ‖ It’s billions of tiny magnetic regions working together.”

> “Time itself did not change. ‖ Maybe the way you experience life did—”

### Pause anti-patterns

- Trailer silence meant to scare  
- Pausing after every word  
- No pauses at all (AI rush)  
- Long dead air that feels like a buffering error

## 8. Emphasis Rules

### What deserves emphasis

| Deserve weight | Why |
|----------------|-----|
| Curiosity pivots | Opens the question |
| Myth corrections | Quiet firmness (“not simply…”) |
| Twist lines | Model upgrade |
| Perspective shift | Afterimage |
| Integrity hedges | Credibility (underplayed, not spotlighted) |

### What does not

- Every adjective  
- Every number  
- The CTA  
- Filler intensifiers the script should not have (“amazing,” “insane”)

### Emphasis technique

Prefer **slight slowdown + clarity** over volume spikes.  
Curionex emphasis is *precision*, not *punch*.

### Density rule

In a 60s Short, only a handful of lines should feel “marked.”  
If everything is emphasized, nothing is.

## 9. Things Never To Do

| Forbidden | Failure mode |
|-----------|--------------|
| Fake excitement | Trust collapse |
| Shouting | Brand break |
| Artificial suspense | Clickbait sonic |
| Clickbait voice | “You won’t believe…” energy |
| Radio DJ tone | Entertainment host, not guide |
| TikTok hype voice | Trend performance |
| Monotone AI | Spam association |
| Fast talking | Anxiety; lost science |
| Overacting | Melodrama |
| Whisper-ASMR gimmick | Novelty over clarity |
| Sarcasm at the audience | Contempt |
| Laughing through serious integrity lines | Undercuts unknowns |

> Callout: **If the take would work as a movie trailer for a thriller, discard it.**

## 10. ElevenLabs Guidance

Keep guidance **provider-capable** and **brand-first**. Do not hardcode a single commercial voice ID in this Bible—voice IDs live in studio config / session notes.

### Selection criteria (any provider)

| Criterion | Pass |
|-----------|------|
| Timbre | Warm-neutral adult; clear midrange |
| Accent | Clear international English; consistent across catalog |
| Energy | Naturally calm; not “announcer” |
| Sibilance | Controlled; not harsh on “science,” “space” |
| Plosives | Manageable with good mic technique / processing |
| Believability | Passes “trusted guide” test muted-video |

### Parameter philosophy (ElevenLabs-class controls)

Exact UI labels vary by model; apply the *intent*:

| Control intent | Curionex guidance |
|----------------|-------------------|
| **Stability** | Prefer **medium-high** — consistent guide, not improv actor. Avoid chaos/variability that injects fake drama. |
| **Similarity / clarity lock** | Prefer **high enough** to keep brand timbre stable across episodes. |
| **Style exaggeration** | Prefer **low**. Style exaggeration is where “trailer voice” sneaks in. |
| **Speaker boost** | Use **lightly** if it improves presence without harshness; never as a substitute for good scripting. |
| **Speed** | Start near natural; finish with **pause design**, not chipmunk rate. |

### Generation practice

1. Generate with **low style / high consistency**.  
2. Listen specifically to Hook, Twist, Ending.  
3. Regenerate lines that spike energy early.  
4. Prefer editorial trim over “make it more exciting” presets.  
5. Keep a reference slate of **approved takes** per persona (chapter 11).

### Do not

- Chase “cinematic” presets  
- Stack multiple excitement-enhancing effects  
- Publish the first take that is merely intelligible

## 11. Voice Personas

Three approved narrator personas. Same brand; different colors.

### Persona A — Primary Curionex Narrator

| | |
|--|--|
| **Role** | Default brand voice for most Shorts |
| **Gender presentation** | Flexible; prioritize timbre & trust over gender |
| **Color** | Warm-neutral, curious, clear |
| **Best for** | Psychology, mind, biology, general science, finales |
| **Avoid** | Forcing this persona into parody energy |

**Reference feeling:** A thoughtful friend who reads Nature for pleasure and never needs to prove it.

### Persona B — Alternative Female Narrator

| | |
|--|--|
| **Role** | Equal-authority alternative; not “softer = less smart” |
| **Color** | Intelligent warmth; precise consonants; calm confidence |
| **Best for** | Body science, perception (blink/yawn), human topics, education-forward cuts |
| **Avoid** | Casting as “gentle only”; keep the same integrity spine |

**Reference feeling:** Trusted science communicator—clarity first, charm second.

### Persona C — Alternative Documentary Narrator

| | |
|--|--|
| **Role** | Slightly more observational / Earth-documentary color |
| **Color** | Measured, spacious, landscape patience |
| **Best for** | Space, Earth history, deep-time (dinosaurs, black holes), physics with scale |
| **Avoid** | Turning documentary into thriller VO |

**Reference feeling:** BBC Earth patience without imitation branding.

### Persona selection rules

1. One persona per published Short (no mid-video switches).  
2. Series consistency beats novelty casting.  
3. Persona never overrides chapters 1–9.  
4. Audition all personas against the **sonic brand test**.

## 12. Script Category Guidance

Brand identity stays fixed. Emphasis and space flex by category.

| Category | Narration emphasis | Watch-outs |
|----------|--------------------|------------|
| **Space** | Wonder + humility; more reflection pauses | No trailer doom |
| **Technology** | Clarity; demystify; light smile on “not magic” | No geek-flex speed |
| **Psychology / Mind** | Intimate; personal recognition (GS-001, GS-010) | No therapist voice / advice tone |
| **History / Deep time** | Documentary patience; survival wonder (GS-008) | No disaster-movie climb |
| **Biology / Body** | Close, human, unembarrassed about ordinary acts | No medical-ad urgency |
| **Physics** | Intuition-first; calm confidence (GS-003, GS-007) | No equation lecture cadence |

### Cross-category constants

- Same emotional curve shape  
- Same pause ethics  
- Same ban on hype  
- Same soft CTA

## 13. Quality Review

### Voice QA checklist

- [ ] Did it sound **human**?  
- [ ] Was pacing **comfortable** (not rushed, not sleepy)?  
- [ ] Was curiosity **genuine** (not performed)?  
- [ ] Did **pauses** improve understanding?  
- [ ] Was the **ending reflective** rather than loud?  
- [ ] Did intensity **peak at insight**, not at the hook?  
- [ ] Were myths corrected with **calm firmness**?  
- [ ] Did hedges sound **trustworthy**, not weak?  
- [ ] Would this pass the **mute-video brand test**?  
- [ ] Does it match the assigned **persona** without breaking brand?

### Fail immediately if

- Trailer energy in first 3 seconds  
- CTA shouted  
- Twist yelled  
- Ending raced  
- Fake laugh / sarcasm at viewer  
- Monotone machine delivery with no intentional phrasing

### Review listening order

1. Hook only  
2. Twist + ending only  
3. Full take once without picture  
4. Full take with picture

## 14. Gold Narration

### Gold

Production-ready voiceover.

| Bar | Requirement |
|-----|-------------|
| Clarity | Every scientific line intelligible first listen |
| Brand | Calm, curious, trustworthy throughout |
| Curve | No early peak; reflective close |
| Pacing | Lands ~55–60s with intentional pauses |
| Persona | Consistent |
| Integrity | Hedges and unknowns spoken honestly |

### Platinum

Defines how Curionex *sounds* for years.

| Bar | Requirement |
|-----|-------------|
| Afterimage | Listener remembers the *feeling* of the ending |
| Invisible craft | Pauses and emphasis feel inevitable, not designed |
| Category mastery | Perfect fit for topic without leaving brand |
| Reference take | Can train narrators and calibrate AI voices |
| Pairing | Especially powerful with Platinum scripts (GS-005, GS-008, GS-010) |

> Pull quote: *Gold is publishable. Platinum is the house accent.*

## 15. Future Expansion

### Multilingual voices

When Curionex expands languages:

1. **Translate the Editorial Bible intent**, not word-for-word trailer tropes.  
2. Preserve **calm / curious / trustworthy** above local “hype defaults.”  
3. Recalibrate WPM per language; keep **relative** curve (slower ending, restrained hook).  
4. Cast personas with local authenticity—never “accent as gimmick.”  
5. Run the same mute-video brand test with bilingual reviewers.  
6. Unknowns and hedges must remain culturally natural—not stiffer than English.

### Future AI narration systems

- This Bible is the **policy layer**; model settings are implementation.  
- Any new TTS vendor must map to chapter 10 intents (stability, low style exaggeration, etc.).  
- Do not optimize solely for platform watch-time algorithms if it breaks trust.

## 16. Appendix — Checklists

### A. Narrator session checklist

- [ ] Read Master Script silently once  
- [ ] Mark twist + perspective lines  
- [ ] Confirm pronunciations with editorial  
- [ ] Cold timed read  
- [ ] Record with low intensity first  
- [ ] Check hook / twist / ending in isolation  
- [ ] Soft CTA last  

### B. ElevenLabs / AI operator checklist

- [ ] Persona selected and documented  
- [ ] Stability / similarity biased to consistency  
- [ ] Style exaggeration kept low  
- [ ] No cinematic preset  
- [ ] Hook not over-energized  
- [ ] Ending has space  
- [ ] Export labeled with script ID + persona + take  

### C. Director / QA sign-off

- [ ] Chapter 13 checklist passed  
- [ ] Gold or Platinum declared  
- [ ] Notes filed for regenerations  
- [ ] Pair approved with picture without requiring shout-mix
